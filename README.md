# Fishcamp para Android

Instaladores (APK) do app de celular do Fishcamp. Baixe pela página https://fishcamp.space/download.

O código fica no repositório privado do Fishcamp; aqui só ficam os releases (tag `mobile-v<versão>`). O app atualiza sozinho o próprio código; um APK novo só sai quando muda a parte nativa.
